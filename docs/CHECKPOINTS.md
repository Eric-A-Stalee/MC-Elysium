# Development checkpoints

Two preserved branches mark the main turning points of the first-dawn work.
The default branch contains the complete alpha 22 chapter.

| Checkpoint | Playable boundary | Verification |
|---|---|---|
| [Alpha 21 — Working Forge](https://github.com/Eric-A-Stalee/MC-Elysium/tree/checkpoint/alpha21-working-forge) | A restored foundry becomes a physical, persistent three-stroke press. Material bills, moving hammer geometry, fuel loss, obstructions and output collection work together. | 68 required server GameTests; ten actual client views. |
| [Alpha 22 — First Dawn](https://github.com/Eric-A-Stalee/MC-Elysium/tree/checkpoint/alpha22-first-dawn) | Useful smithing rewards, a deliberate first sunset, three surface watch traditions, cinder encounters and wards, and a revisitable choice of a living sky or enduring golden hour. | 73 required server GameTests; twenty actual client scenes and a focused final warning-glow capture. |

Start a fresh alpha world or fully regenerate Elysium when changing between
these checkpoints. Old-world migration is not part of their contract.

The [first-dawn guide](FIRST_DAWN.md) describes the current player route;
[testing notes](TESTING.md) give exact source commits, workflow runs and limits.
A wider Tartarus realm remains future development. The surface can remain a
peaceful home for players who never deliberately start the Great Hammer.
